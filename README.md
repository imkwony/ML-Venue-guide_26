# Causal ML Venue Guides — 인과추론 연구자를 위한 학회·저널 안내

머신러닝·AI의 flagship 학회와 인과추론 커뮤니티의 학회·저널을, 채택률·Impact Factor·h5-index 같은 공개 품질 지표와 함께 한곳에서 살펴볼 수 있는 링크 허브입니다.

## 공개 사이트
https://imkwony.github.io/ML-Venue-guide_26

## 구성

- 머신러닝 · AI: NeurIPS, ICML, ICLR, AAAI (학회) · JMLR (저널)
- 인과추론: UAI, CLeaR, AISTATS (학회) · Journal of Causal Inference, JASA, Biometrika (저널)

## 품질 지표

각 카드에는 다음과 같은 공개 지표를 함께 표기합니다.

- 학회: 최근 연도 채택률(제출 건수 대비 채택 건수), 창립 연도, 커뮤니티 성격
- 저널: Journal Citation Reports(JCR) 기준 Impact Factor·JCR 쿼타일, 또는 CORE 랭킹·Google Scholar Metrics h5-index

지표는 2026년 9월 기준 공식 통계·JCR·Google Scholar Metrics를 근거로 작성했으며, 매년 갱신되므로 최신 수치는 각 venue의 공식 사이트에서 확인하는 것을 권장합니다.

## 기술 구성

- 단일 정적 `index.html`
- 외부 프레임워크·폰트·스크립트 없음
- 우측 상단 버튼으로 한국어·영어 전환, 새로고침 후에도 선택한 언어 유지
- 각 카드의 두 번째 소개 문단은 작은 회색 인용형 보조 설명으로 표시
- 데스크톱과 모바일 모두 한 줄에 한 venue를 표시하는 반응형 레이아웃
- GitHub Pages가 `main` 브랜치의 저장소 루트에서 배포

## 지표 검증

2026-09-10 기준 공식 통계(NeurIPS/ICML/ICLR/AAAI/UAI/AISTATS 채택률), Journal Citation Reports(JASA/Biometrika/Journal of Causal Inference Impact Factor), Google Scholar Metrics/CORE 랭킹(JMLR)을 근거로 작성했습니다.
